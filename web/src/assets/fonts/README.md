# 화면용 폰트

| 파일 | 원본 | 라이선스 |
|---|---|---|
| `dowon-sans-400.woff2`, `-500`, `-600` | IBM Plex Sans KR Regular, Medium, SemiBold | SIL OFL 1.1, `OFL-IBMPlexSansKR.txt` |
| `noto-serif-kr-600.woff2` | Noto Serif KR 가변 글꼴의 wght 600 | SIL OFL 1.1, `OFL-NotoSerifKR.txt` |

원본은 [google/fonts](https://github.com/google/fonts) 저장소 `fbe81817505e`의 `ofl/ibmplexsanskr`, `ofl/notoserifkr`이다.

영문과 KS X 1001 한글 2,350자로 줄였다. 범위 밖 글자는 기기의 글꼴로 나온다. 다시 만드는 방법은 `web/scripts/build_fonts.py`에 있다.

IBM Plex의 라이선스는 "Plex"를 예약 글꼴 이름으로 둔다. 줄인 파일은 수정본이므로 글꼴 이름을 Dowon Sans로 바꿨다.
