# 사용 관찰 절차

> 상태: 2026-11-05 팀 확정. 최종 목표와 결과 분류는 [SPEC 6절 제품 사용 검증](../SPEC.md#제품-사용-검증)과 같다. 관찰 동의 문구와 기록 보관 기간은 아직 정하지 않았다(확인 필요). [처리방침](../PRIVACY.md)은 서비스 이용만 다룬다.

## 1. 대상

- 팀원 3명의 지인 중 날짜·목적지가 정해진 출발 전 여행 그룹 5개를 모집 마감일(미정)까지 확정한다. 출발일은 최종 평가 뒤여도 된다. 결과 확인 세션만 최종 평가 전에 끝낸다.
- 그룹은 2~8명이고 동행 관계는 제한하지 않는다. 팀원 본인이 속한 그룹은 뺀다.
- 11/11~11/18 동료 사용자는 세지 않는다. 실제 출발을 앞둔 동료 그룹만 예외로 받는다.

## 2. 진행

1. 방장이 방을 만들고 동행이 각자 답한다.
2. 결과 확인 세션은 30분이다(대면 또는 화상). 연장하지 않는다.
3. 진행자는 아래 질문만 같은 순서로 쓴다. 선택을 유도하는 말("이 조항이 좋지 않나요?")은 하지 않는다.
    - "실제로 사용할 조항이 있나요? 없다면 없다고 말씀해 주세요."
    - "그 조항은 누구에게, 왜 적용하나요?"
    - "다른 동행 한 명의 바람이나 한계가 결과의 어느 문장에 반영됐는지 말씀해 주세요." 이어서 그 동행에게 "이 설명의 취지가 맞나요?"
    - "그대로 쓸 조항과 고쳐 쓸 조항을 나누고 이유를 말씀해 주세요. 고칠 조항이 없으면 그 이유를 말씀해 주세요."
4. 설명은 공유 결과 문장 범위에서 한다. 메모 원문 공개를 요구하지 않는다.

## 3. 기록

그룹마다 다음을 남긴다. 실명·연락처·녹음 같은 원자료는 저장소에 넣지 않고, 비식별화한 기록만 둔다(AGENTS 4절).

- 선택한 조항과 적용 대상
- 선택·수정 이유에 대한 실제 발언
- 다른 동행의 요구를 설명한 발언과 당사자의 확인
- 진행자가 설명하거나 도운 내용
- 두 판정자의 최초 판정, 불일치 이유, 최종 합의

## 4. 분류와 판정

| 결과 | 기준 |
| --- | --- |
| 활용 성공 | 실제 여행에 사용할 조항을 1개 이상 고르고 적용 대상과 선택 이유를 설명한다. 조건부 대안은 필요한 변경 조건까지 고른 경우만 센다 |
| 활용 실패 | 결과를 검토했지만 고르지 않았다. 30분 안에 고르지 못한 경우도 여기에 넣는다. 이유를 기록한다 |
| 품질 실패 | 요구 왜곡 등으로 결과를 쓰지 못했다 |
| 관찰 중단 | 여행 취소·불참 등으로 관찰하지 못했다. 이유를 기록한다 |

결과 열람, 이미지 저장, 방장의 선택 버튼은 활용 성공으로 세지 않는다.

정성 목표는 다음을 모두 충족한 그룹을 달성으로 센다.

- 서로 다른 참여자 2명 이상이 다른 동행의 바람·한계가 결과의 어느 문장에 반영됐는지 설명하고, 해당 동행이 취지가 맞다고 확인한다.
- 그룹이 그대로 쓸 조항과 고칠 조항을 이유와 함께 나눈다. 고칠 조항이 없다고 판단하면 그 이유를 기록한다.

판정은 진행자의 기록을 세션에 없던 팀원 1명이 따로 보고, 진행자와 판정이 다른 건만 합의한다.

## 5. 목표와 한계

- 정량: 사전 확정한 5개 중 활용 성공 3개 이상(60%).
- 정성: 사전 확정한 5개 중 달성 3개 이상.
- 두 목표는 따로 센다. 분모는 사전 확정한 5개이며, 품질 실패와 관찰 중단도 분모에 남긴 채 원인을 따로 적는다.
- 모집 마감일까지 5개를 채우지 못하면 확정한 수 N을 분모로 하고, N의 60% 이상(올림)을 각 목표의 기준으로 한다(4개면 3개, 3개면 2개). 부족한 수와 이유는 한계로 밝힌다. N이 3 미만이면 목표를 판정하지 않고 관찰 부족으로 보고한다.
- 탐색적 목표다. 그룹 하나가 20%p라 일반 여행자의 활용률이나 효과로 넓혀 해석하지 않는다. 지인 모집이라 반응이 호의적일 수 있다.
- 출발 전 세션으로는 조율 방법의 이해와 선택까지만 본다. 여행 중 갈등이 줄었다고 주장하지 않는다.
