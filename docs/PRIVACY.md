# 도원결의 개인정보 처리방침(초안)

> 상태: 2026-11-04 초안. 팀 ItBM이 운영하는 모바일 웹 ‘도원결의’에 적용한다. ‘확인 필요’ 표시는 법률 확인 뒤 채운다. 제품 범위와 운영 정책은 [SPEC](SPEC.md) 4절, 데이터 흐름은 [ARCHITECTURE](ARCHITECTURE.md)를 따른다.

## 1. 처리 목적

여행 동행이 같은 가상 상황에 각자 답한 응답으로 추천 협약서를 만들고, 방장이 결과를 선택·편집해 이미지로 저장하도록 하기 위해 개인정보를 처리한다. 다른 목적으로 쓰지 않는다.

## 2. 수집 항목

| 구분 | 항목 | 수집 시점 |
|---|---|---|
| 필수 | 이름 또는 별명 | 방장이 방을 만들 때 동행 전원의 이름·별명을 입력한다 |
| 선택 | 성별, 나이대, MBTI | 방 생성 시 방장이 입력할 수 있다. 문항 개인화에만 쓰고 공개하지 않는다 |
| 응답 | 선택지와 메모(최대 300자) | 각 참여자가 답변을 제출할 때 |
| 자동 | 푸시 구독 정보, 접속 기록(IP, 시각, 요청 경로) | 알림을 허용했을 때, 서비스 접속 시 |

실명이 아닌 별명 사용을 권한다. 방장은 동행의 이름을 대신 입력하므로 입력 전에 동행에게 알린다. 메모에는 건강 상태 등 조율에 필요하지 않은 개인 사정을 쓰지 않도록 화면에서 안내한다.

## 3. 공개 범위

개인의 선택·메모 원문과 성별·나이대·MBTI는 다른 참여자와 공유 이미지에 공개하지 않는다. 답변에 담긴 바람·한계는 등록한 이름·별명과 함께 추천 결과에 반영될 수 있다. 제출 후에는 본인도 답변 원문을 다시 볼 수 없다.

## 4. 보관 기간과 파기

- 현재(1차 MVP): 방 단위 삭제 명령으로 요청 시 삭제한다. 자동 삭제는 아직 없다.
- 30일 자동 만료(F7)를 구현한 뒤에는 방 생성 시점부터 30일이 지나면 방·프로필·답변·결과·푸시 구독·접속 기록을 삭제하고 초대 링크 조회를 막는다.
- 사용자가 기기에 저장한 이미지는 서버 삭제의 대상이 아니다.
- 보관 기간 문구의 최종 표현: 확인 필요.

## 5. 처리 위탁과 국외 이전

| 수탁자 | 위치 | 처리 내용 | 비고 |
|---|---|---|---|
| OpenAI | 미국 | 문항 생성과 추천 생성을 위해 여행 정보·프로필 ID·응답(선택·메모)을 전송한다 | 응답 저장(`store`)을 끈다. OpenAI는 API 데이터를 학습에 쓰지 않으며 남용 감시 로그를 최대 30일 보관한다고 밝힌다(2026-11-04 공식 문서 확인) |
| Amazon Web Services | 대한민국(서울 리전) | 서버·데이터베이스·로그 운영 | CloudFront 엣지가 국외에서 요청을 처리하는지: 확인 필요 |

국외 이전 고지의 법적 요건과 문구: 확인 필요.

## 6. 안전 조치

- 전송 구간은 HTTPS(TLS 1.2 이상)만 허용한다.
- 데이터베이스는 저장 암호화를 켜고 서버에서만 접근한다.
- 서버 로그에는 메모 원문, 성별·나이대·MBTI, 이름·별명을 남기지 않고 ID로 기록한다.
- 방장 권한 토큰은 해시로만 저장한다.

## 7. 이용자의 권리

참여자와 방장은 방의 삭제를 요청할 수 있다. 요청 수단: 확인 필요(팀 공용 연락 수단 결정 뒤 기재). 삭제 요청은 방 단위로 처리하며 처리 결과를 알린다.
