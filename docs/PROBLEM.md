# 문제 정의서

## 1. 한 문장 문제

친구와 자유여행을 하는 사람이 일정·활동을 조율할 때 자신의 바람과 한계를 충분히 말하지 못하거나 반영하지 못해, 원치 않는 선택을 따르거나 아쉬움을 남긴다.

여행 중 입장을 확인하고 조정하는 어려움은 인터뷰 근거가 있다. 여행 전 가상 상황에 답하고 추천 협약서를 확인하는 방식이 이 어려움을 줄일지는 해결 가설이다.

## 2. 대상과 비대상

- 1차 사용자: 친구와 자유여행을 앞두고 일정·활동을 함께 정하는 동행자. 활동을 계속하려는 사람과 쉬거나 변경하려는 사람 모두를 포함한다.
- 비대상: 혼자 여행하는 사람, 정해진 단체 일정의 운영자, 여행 중 실시간 예약·동선 조정을 원하는 사람.
- 다른 동행 관계는 현재 제품의 대상에서 제외한다. 핵심 장면의 근거는 친구 여행이다.

## 3. 증거

인터뷰는 참여자의 회고이다. 동행 전원의 입장이나 직접 관찰로 확대하지 않는다. 전체 기록은 [인터뷰 문서](research/interviews.md), 아래 링크는 각 로그의 사건 흐름이다.

| 확인한 내용 | 근거 | 해석의 범위 |
|---|---|---|
| 계획자의 수고 때문에 귀가 희망을 처음에는 말하지 못했다. 피곤하다고 말한 뒤 귀가를 제안해 수긍을 얻었다. | [로그 1](research/records/log-01.md#3-사건-흐름), 인천 사례 | 표현 주저의 근거. 계획자가 서운했을 것이라는 설명은 응답자의 추측이다. |
| 노을 사진과 쇼핑 요구가 갈렸고, 쇼핑 시간을 제한한 뒤 해변으로 이동했다. | [로그 2](research/records/log-02.md#3-사건-흐름) | 시간 나누기로 두 활동을 일부 수행한 사례. 일방 양보의 서운함은 당시 예상이다. |
| 펜션 수영장과 바다 수영 의견이 갈렸다. 다수결 후 편리한 해수욕장을 찾았고, 본인은 선택과 과정에 불만이 없었다. | [로그 6](research/records/log-06.md#3-사건-흐름) | 선택 차이가 곧 갈등·불만은 아니라는 반례이다. |
| 계획 방식에 대한 바람을 끝까지 주장하지 않았고, 현지에서 다음 날 일정을 정할 때 하고 싶은 말을 다 못 했다고 회고했다. | [로그 8](research/records/log-08.md#3-사건-흐름) | 표현 유보와 준비 부담의 근거. 특정 활동 두 개가 대립한 장면으로 세지 않는다. |
| 루지 취소 후 아쉬움을 일부만 말했고, 이후 계획·바람 공유를 중단했다. 같은 친구와 장기 여행을 하고 싶은 마음이 줄었다. | [로그 9](research/records/log-09.md#3-사건-흐름) | 본인의 행동·평가이다. 동행의 의도·감정은 확인되지 않았다. |
| 메뉴가 달라 따로 식사하고 다시 만나거나 두 팀으로 나뉘었다. | [로그 4](research/records/log-04.md#3-사건-흐름), [로그 12](research/records/log-12.md#3-사건-흐름) | 별도 행동도 조율 방법이다. 항상 함께해야 한다는 기대를 모든 여행에 적용하지 않는다. |

기존 대화와 즉석 절충으로 충분했던 사례도 있다. 로그 2·6의 참여자는 선택에 만족했고, [로그 10](research/records/log-10.md#3-사건-흐름)은 원하는 활동을 하지 못했어도 크게 기분 나쁘지 않았다고 했다. [로그 7](research/records/log-07.md)·[로그 13](research/records/log-13.md)은 갈등이 없었다고 답했으며, 로그 13은 특정 사건을 재구성하지 못했다.

출발 전 합의 여부는 명시적으로 답한 사례만 집계한다. 로그 4의 놀이공원 사례에는 미리 합의하지 않았다는 답이 있지만, 다른 로그에서 언급되지 않은 내용을 합의 부재로 집계하지 않는다. [워크플로 관찰 1](research/interviews.md#c-워크플로-관찰-기록)은 9/30에 여행 당사자가 출발 전 단톡방 기록을 역추적한 자료이다. 링크 공유와 제안 응답은 기록으로 확인했으며, 전화에서의 거절과 결정 역할은 응답자 진술로 구분한다. 이 기록은 사전 체험의 사용 동기·부담을 측정한 자료가 아니다.

## 4. 반증 조건

### 문제의 실재

집계 대상은 친구와 여행했다고 확인된 로그 1·2·3·4·6·8·9·10·11·12의 참여자 10명이다. 연인 여행인 로그 7·13·14와 관계가 불명확한 로그 5는 분모에서 제외한다. 이 자료는 다른 동행 관계의 참고 사례로 보존한다. 같은 사람의 여러 사건과 로그 10의 후속 관찰은 인원을 늘리지 않는다.

- 요구 차이: 여행의 특정 활동·메뉴·휴식 선택에서 본인과 동행이 원하는 것이 달랐다는 기록이 있으면 포함한다. 다툼이나 불만이 없어도 포함하며, 일정 변경의 전 과정을 재구성할 수 있어야 한다는 조건은 두지 않는다. 일반적인 계획 방식 차이만 있는 경우는 제외한다.
- 표현 유보: 여행 준비·현지 조율에서 본인이 바람이나 감정을 말하지 못했거나 일부만 말했다고 회고한 경우를 포함한다. 단순한 양보·간접 표현, 타인의 감정 추측, 진행자가 제시한 이유에 동의한 답변만으로는 포함하지 않는다.
- 표의 ‘미확인’은 해당 기록에서 집계 조건을 확인하지 못했다는 뜻이며, 실제로 그런 경험이 없었다는 뜻은 아니다.

### 해결 가설

출발 전 같은 가상 상황에 독립적으로 답하고, 각자의 요구와 한계를 보존한 추천 협약서를 확인하면 일행이 서로 다른 의견을 이해하고 실제로 사용할 조율 방법을 정하는 데 도움이 될 것이다. [Job Story의 Pull](research/interviews.md#d-핵심-job-story)과 9/23 회의의 사전 체험 방향에 근거한 서비스 가설이다.

- 반증할 행동: 응답 조건을 제대로 반영한 결과를 읽고도 사용할 조항을 하나도 고르지 못하고, 결과를 참고하지 않은 채 기존 대화에서 같은 논의를 처음부터 다시 한다.
- 품질 오류 구분: 응답 누락·왜곡이나 조건 위반 때문에 결과를 버린 경우는 추천 품질 실패로 기록한다. 해결 방식 자체의 실패와 따로 센다.
- 판정 범위: 현재 자료는 인터뷰와 모델 출력 실험이다. 해결 가설은 품질 기준을 충족한 추천을 실제 그룹이 사용하는 관찰에서 판정한다. 대상 그룹·관찰 시간·기각 기준은 [SPEC의 제품 사용 검증](SPEC.md#제품-사용-검증)에서 관리한다.
- 실제 여행에서 불만이 줄어드는 효과는 여행 후 별도로 확인한다. 사전 결과 조회·저장만으로 갈등 예방을 입증하지 않는다. 제품은 이름으로 본인을 확인하지 않으므로 실제 사람 단위의 사용 관찰·재사용 조사는 별도 확인한 참여자를 기준으로 한다.

## 5. 성공의 정의

| 행동 지표 | 계산·관찰 방법 | 해석 |
|---|---|---|
| 응답 수 도달률 | 응답을 시작한 방 중 설정 인원만큼 완전한 답변 묶음이 제출된 방의 비율 | 같은 이름의 별도 제출도 센다. 실제 서로 다른 동행자의 전원 응답률로 해석하지 않는다. |
| 조기 생성 비율 | 생성한 방 중 설정 인원 도달 전에 방장이 생성을 시작한 방의 비율 | 제외된 등록 프로필 수·반영 응답 수를 함께 기록한다. |
| 추천 활용률 | 품질 기준을 충족한 결과를 검토한 테스트 그룹 중 실제로 사용할 조항을 하나 이상 정한 그룹의 비율 | 진행자가 조항과 선택 이유를 기록한다. 방장 편집이나 이미지 저장만으로 전원 수락을 추정하지 않는다. |
| 결과 저장률 | `proposed` 결과를 조회한 방 중 추천 협약서 이미지를 저장한 방의 비율 | 저장 행동을 측정하며 만족도와 구분한다. |
| 다음 여행 재사용 | 다음 여행 계획이 확인된 기존 이용 그룹·참여자 중 새 방을 만든 비율 | 재사용 기회가 없던 사람은 분모에서 구분한다. |

메모 작성률은 입력 부담과 정보 충분성을 살피는 보조 지표로 둔다. 메모가 선택 사항이므로 빈 메모를 표현 실패로 단정하지 않는다. 사용 관찰에서는 대상 그룹·기간·지표별 목표 비율을 사전에 기록한다.
